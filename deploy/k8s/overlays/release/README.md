# Phase 02: digest-only Kubernetes overlay

This directory is generated by `make phase2-render` after the Phase 2 release
workflow uploads its `release.json` file. The generated `kustomization.yaml`
transforms the Phase 1 placeholder image to `ghcr.io/OWNER/sentinelflow-api@sha256:...`.

Do not invent a digest, use `latest`, or deploy the original Phase 1 placeholder.
Kubernetes rollout and Argo CD reconciliation are deliberately Phase 4 features.

```bash
make phase2-render
kubectl kustomize deploy/k8s/overlays/release
# Review the transformed manifest; apply only in an authorized cluster.
```

`make phase2-render` is expected to fail until you provide a real release manifest
from GitHub Actions. The parent `../../base` reference is resolved relative to this
overlay directory, not relative to the repository root.
